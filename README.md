💰 Personal Expense Tracker

A full-featured Personal Expense Tracker web application built using Python, Streamlit, SQLite, Pandas, and Matplotlib.
This application helps users manage daily expenses, monitor spending habits, set budgets, and visualize financial analytics through interactive charts.

🚀 Features
🔐 User Registration & Login Authentication
➕ Add, View and Delete Expenses
📂 Expense Categorization
📅 Monthly Budget Management
📊 Expense Analytics & Interactive Charts
🔍 Filter Expenses by Date/Category
📁 Export Data to CSV & Excel
🗄️ SQLite Database Integration
📈 Spending Visualization using Matplotlib
💡 Clean and User-Friendly Interface with Streamlit
🛠️ Technologies Used
Python
Streamlit
SQLite
Pandas
Matplotlib

⚙️ Installation & Setup
1️. Clone the Repository
git clone https://github.com/kunalsuryawanshi1717-web
2️. Navigate to Project Folder
cd personal-expense-tracker
3️. Install Dependencies
pip install -r requirements.txt
4️. Run the Application
streamlit run app.py
